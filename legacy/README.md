# Arsip

Skrip Python di folder ini berasal dari fase awal proyek, sebelum seluruh logika
penyandingan dipindahkan ke `sirup_exporter.user.js`.

**Tidak dipakai lagi dan tidak bisa dijalankan apa adanya**: jalur file-nya masih
menunjuk ke direktori kerja sementara di mesin penulis aslinya
(`C:\Users\...\.system_generated\steps\NNN\output.txt`), berisi dump JSON hasil
crawl manual yang tidak ikut disimpan di repo ini.

Disimpan hanya sebagai rujukan bagaimana aturan penyandingan pertama kali
diterjemahkan ke kode.
